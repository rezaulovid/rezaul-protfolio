# Figma-ready SVG layouts

Import the seven original desktop SVG screens plus `08-mobile-home.svg` and `09-mobile-project-detail.svg` from `public/images/` into a Figma Design file by dragging them onto the canvas.

The SVGs are editable vector imports, not a native `.fig` document. Imported SVGs may need ungrouping, text reflow, Auto Layout setup, component extraction, responsive constraints and prototype links in Figma. Use the desktop screens for visual direction and the two mobile screens as responsive references.
